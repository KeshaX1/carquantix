Put brand logo files in this folder.

Supported formats:
- .svg
- .webp
- .png
- .jpg
- .jpeg

Preferred order:
- .svg for vector logos
- .webp for raster logos

Filename rule:
- lowercase
- spaces become "-"
- special characters are removed

Examples:
- Audi -> audi.svg
- Alfa Romeo -> alfa-romeo.png
- Mercedes-Benz -> mercedes-benz.svg
- Aston Martin -> aston-martin.webp

If no matching logo file exists, the UI falls back to the 2-letter monogram automatically.
